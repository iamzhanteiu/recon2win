# setuptools ships ``pkg_resources``. dirsearch imports it at module load —
# Python 3.12+ removed pkg_resources from the stdlib, so without setuptools
# dirsearch crashes with ModuleNotFoundError the instant you run it
# (count=0, 0.73s in the wild).
#
# The UPPER bound matters: setuptools 81.0.0 (2025) *removed* the bundled
# pkg_resources, so a bare ``>=68`` now resolves to a version that DOESN'T
# ship it and dirsearch breaks again. Pin below 81 until dirsearch drops
# its pkg_resources import.
setuptools>=68.0,<81
